متجر إلكتروني شامل مثل AliExpress - منصة تسوق عصرية وموثوقة

## 🌟 الميزات

- ✅ نظام المستخدمين والبائعين
- ✅ عرض وإدارة المنتجات
- ✅ عربة التسوق والدفع
- ✅ نظام التقييمات والمراجعات
- ✅ البحث والتصفية المتقدمة
- ✅ لوحة تحكم المسؤول
- ✅ نظام الشحن والتتبع
- ✅ نظام الفئات والعلامات التجارية

## 🛠️ التقنيات المستخدمة

### Frontend
- **Next.js 14** - React Framework
- **React** - UI Library
- **Tailwind CSS** - Styling
- **Redux/Context API** - State Management
- **Axios** - HTTP Client

### Backend
- **Node.js** - Runtime
- **Express.js** - Web Framework
- **MongoDB** - Database
- **JWT** - Authentication
- **Multer** - File Upload

### DevTools
- **ESLint** - Code Quality
- **Prettier** - Code Formatting
- **Jest** - Testing
- **Docker** - Containerization

## 🚀 البدء السريع

### المتطلبات
- Node.js v18+
- MongoDB
- npm أو yarn

### التثبيت

```bash
# Clone the repository
git clone https://github.com/hichamurmansour-dotcom/chop-marketplace-app.git

# Install dependencies
cd frontend && npm install
cd ../backend && npm install
```

### تشغيل التطبيق

```bash
# Terminal 1 - Backend
cd backend
npm run dev

# Terminal 2 - Frontend
cd frontend
npm run dev
```

الآن يمكنك الوصول إلى التطبيق على: `http://localhost:3000`
